# account_account

## Source system
This table originates from an Odoo ERP system, as evidenced by the naming convention (`account_account`), the use of `JSONB` for localized fields (`name`, `code_store`), and the standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`).

## Functional process 
This table supports the General Ledger and Chart of Accounts management process. It defines the structure of the accounting system, categorizing financial transactions into specific accounts (e.g., assets, liabilities, equity, income, expenses) and determining whether those accounts are eligible for reconciliation or are restricted from trade activities.

## Description
One row in this table represents a single account definition within the organization's Chart of Accounts. This is a raw landing table in the Staging layer, capturing the current state of account configurations as defined in the source ERP.
