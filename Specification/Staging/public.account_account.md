# account_account

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `account_account` and the presence of columns like `create_uid`, `write_uid`, and `JSONB` fields for multi-language support are characteristic of the Odoo ORM's database schema.

## Functional process 
This table supports the General Ledger and Chart of Accounts management process. It defines the structure of accounts used for financial reporting, tracking balances, and categorizing transactions within the accounting module.

## Description
One row represents a single financial account within the chart of accounts. This is a raw landing table in the staging layer, containing the base configuration, classification, and metadata for each account used in the system.

## Caveats for downstream consumers

- **Timestamps:** Timestamps are stored in UTC.
- **Soft Deletes:** This table does not explicitly show a soft-delete column, but the `deprecated` boolean should be used to filter out inactive accounts in financial reports.
