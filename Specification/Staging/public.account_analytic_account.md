# account_analytic_account

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention `account_analytic_account`, the use of `JSONB` for multi-language fields (`name`), and the standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`).

## Functional process 
This table supports the analytical accounting and cost tracking process. It represents individual analytic accounts used to track costs, revenues, and budgets across different projects, departments, or contracts, allowing for financial reporting that is independent of the standard general ledger structure.

## Description
One row represents a single analytic account record within the Odoo system. This is a raw landing table in the staging layer, containing the direct state of the analytic account entity as captured from the source database.

## Caveats for downstream consumers

- **PII/Sensitive Data:** The `name` field may contain project or client names; `partner_id` links to entities that may contain PII.
- **Timestamps:** `create_date` and `write_date` are typically stored in the server's local time zone; verify the Odoo instance configuration for UTC offsets.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless historical/archived data is required.
- **JSONB:** The `name` column is a `JSONB` object. Downstream consumers will need to extract the specific language key (e.g., `name->>'en_US'`) to use this field in reporting.
