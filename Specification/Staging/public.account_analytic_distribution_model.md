## Functional process 
This table supports the automated analytic accounting distribution process. It defines rules that automatically assign analytic accounts to financial entries based on specific criteria such as partners, products, or account prefixes, ensuring that costs and revenues are correctly allocated across analytic dimensions.

## Description
One row represents a single configuration rule for analytic distribution. It acts as a staging entity for the Odoo analytic model, capturing the logic used to map business transactions to analytic accounts. The grain is one row per distribution rule.
