# account_automatic_entry_wizard

## Source system
This table originates from Odoo (formerly OpenERP), as evidenced by the naming convention (`account_automatic_entry_wizard`), the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`), and the sequence-based default for the `id` column.

## Functional process 
This table supports the "Automatic Entry" wizard process in the accounting module, which allows users to automate the creation of journal entries for recurring transactions or the distribution of amounts across multiple accounts. It tracks the configuration and execution parameters for these automated adjustments.

## Description
One row represents a single execution or configuration instance of the automatic entry wizard. It acts as a staging record for the parameters (such as percentage, target account, and total amount) used to generate automated accounting journal entries. This table serves as a raw landed copy of the wizard's state before the resulting financial entries are posted to the general ledger.
