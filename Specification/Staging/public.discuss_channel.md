# discuss_channel

## Source system
This table originates from Odoo (OpenERP), as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `create_date`, and `write_date`, which are standard audit columns in the Odoo ORM. The table structure suggests it manages communication channels within the Odoo Discuss module.

## Functional process 
This table supports the internal communication and collaboration infrastructure of the platform. It tracks the configuration and state of various discussion channels, including direct messages, group chats, and public channels, facilitating the "Discuss" or "Messaging" business process.

## Description
One row in this table represents a single communication channel or chat room instance within the system. It acts as a raw landed copy of the channel configuration, capturing metadata such as channel type, display settings, and lifecycle timestamps. The grain is one row per unique channel identifier.

## Caveats for downstream consumers

- **Timestamps:** All `_date` and `_dt` columns are assumed to be in UTC, consistent with Odoo's internal storage format.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing an audit of historical/deleted channels.
