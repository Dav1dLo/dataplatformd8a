# fetchmail_server

## Source system
This table originates from an Odoo ERP system. The naming convention (e.g., `create_uid`, `write_uid`, `create_date`, `write_date`) and the specific structure of the `fetchmail_server` module are characteristic of Odoo's internal ORM-managed tables.

## Functional process 
This table supports the "Inbound Email Integration" process, specifically managing the configuration of external mail servers (IMAP/POP) that the ERP polls to fetch incoming emails. It facilitates automated lead generation, support ticket creation, or document processing by connecting the ERP to external mail providers.

## Description
One row in this table represents a single configured external mail server connection, including its authentication credentials and polling settings. It serves as a raw landed copy of the Odoo `fetchmail.server` model, capturing the configuration state required for the system's email fetcher service.
