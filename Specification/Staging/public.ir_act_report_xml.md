# ir_act_report_xml

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `ir_act_report_xml` is characteristic of Odoo's "Ir" (Irrelevant/Internal Registry) module, which manages system-level actions and report definitions within the framework.

## Functional process 
This table supports the report management and document generation process. It stores the metadata and configuration for XML-based reports, defining how specific business models (e.g., invoices, sales orders) are rendered, which paper formats are applied, and whether reports should be automatically attached to records.

## Description
One row in this table represents a single report definition or action configuration within the Odoo system. It acts as a raw landed copy of the report registry, capturing the technical configuration, model binding, and file pathing required to trigger report generation.
