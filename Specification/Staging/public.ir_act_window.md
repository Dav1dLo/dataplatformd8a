# ir_act_window

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `ir_act_window` is a standard Odoo internal table name representing "Interface Record Action Window," which defines how views are opened in the Odoo web client.

## Functional process 
This table supports the UI/UX configuration and navigation framework within the Odoo platform. It defines the "Window Actions" that dictate which model to display, which view types (e.g., tree, form, kanban) to render, and the specific domain filters applied when a user clicks a menu item or button in the application.

## Description
One row in this table represents a single window action configuration that controls how a specific data model is presented to the user. It acts as a raw landing copy of the Odoo metadata configuration, defining the behavior of the application interface at the grain of one action definition per row.

## Caveats for downstream consumers

- **JSONB Columns:** The `name` and `help` columns contain JSONB data; use `->>` operator to extract text values for reporting.
- **Timestamps:** Timestamps are stored in UTC as per Odoo standard practice.
- **Domain/Context:** The `domain` and `context` columns contain serialized Python-like strings; these require custom parsing logic if used for downstream filtering.
- **Soft Deletes:** This table does not implement soft deletes; records are typically hard-deleted in the source system.
- **Sensitivity:** No PII is present, but `context` may contain internal system paths or configuration details.
