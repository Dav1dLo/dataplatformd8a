# ir_actions

## Source system
This table originates from the Odoo ERP platform, as evidenced by the `ir_` (Internal Registry) naming convention, the use of `JSONB` for translatable fields (`name`, `help`), and the standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`).

## Functional process 
This table supports the Odoo framework's action management system, which defines how the user interface responds to user interactions (e.g., opening a view, executing a server action, or triggering a report). It manages the binding of these actions to specific models and views within the application.

## Description
One row represents a single action definition within the Odoo system, such as a window action, report action, or server action. It serves as a raw landed copy of the system's action registry, used to determine navigation and UI behavior across the platform.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may be considered PII depending on the downstream environment.
- **Timestamps:** Timestamps are stored in the server's local time; verify the Odoo server timezone configuration before performing time-series analysis.
- **JSONB:** The `name` and `help` columns contain JSONB objects, typically structured as `{"en_US": "Value", "fr_FR": "Valeur"}`. You will need to use the `->>` operator to extract specific language values.
