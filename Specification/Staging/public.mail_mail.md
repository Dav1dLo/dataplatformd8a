# mail_mail

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention (`mail_mail`, `mail_message_id`, `create_uid`, `write_uid`) and the specific sequence-based default value pattern typical of the Odoo ORM.

## Functional process 
This table supports the outbound email communication process within the ERP. It tracks the lifecycle of individual email messages queued for delivery, including their status, scheduling, and any delivery failure diagnostics.

## Description
One row represents a single outbound email message instance, capturing its content, recipient metadata, and delivery state. It serves as a raw staging entity for the Odoo mail delivery queue, providing a granular audit trail of messages processed by the system's mail server integration.

## Caveats for downstream consumers

- **Sensitive Data:** The `body_html`, `email_to`, and `email_cc` columns contain PII and potentially sensitive business communication; ensure these are masked in non-production environments.
- **Timezones:** Timestamps are stored in UTC as per Odoo standard behavior.
- **Data Retention:** The `auto_delete` flag suggests that some records may be purged from the source system shortly after processing; downstream incremental loads must account for potential missing historical data.
- **Content:** `body_html` may contain large amounts of text; ensure downstream storage handles `TEXT` types appropriately to avoid truncation.
