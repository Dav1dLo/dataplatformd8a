# mail_message

## Source system
This table originates from Odoo ERP. The naming convention (e.g., `res_id`, `create_uid`, `write_uid`, `model`) and the specific sequence-based primary key pattern are characteristic of the Odoo framework's messaging and chatter system.

## Functional process 
This table supports the Odoo "Discuss" and communication tracking process. It acts as the central repository for all internal notes, emails, and system notifications linked to specific business records (e.g., sales orders, invoices, or CRM leads), facilitating audit trails and communication history.

## Description
One row represents a single communication event, such as an email sent/received, an internal note, or a system-generated notification. This is a raw landing table in the Staging layer, capturing the full history of messages associated with various Odoo models.

## Caveats for downstream consumers

- **Sensitive Data:** The `body` and `email_from` columns may contain PII or sensitive business communication; ensure appropriate masking for non-privileged users.
- **Timezones:** Timestamps (`date`, `create_date`, `write_date`) are stored in UTC by Odoo.
- **Soft Deletes:** This table does not implement a standard `active` flag; records are generally immutable once created, though they may be updated.
- **Data Volume:** The `body` column can contain large HTML blobs; queries selecting this column should be filtered by date or model to avoid performance degradation.
