# portal_share_res_partner_rel

## Source system
This table originates from an Odoo ERP system. The naming convention `res_partner` is the standard internal identifier for the "Partner" (customer/vendor/contact) model in Odoo, and the `_rel` suffix indicates a many-to-many join table generated by the Odoo ORM to link portal sharing configurations to specific partners.

## Functional process 
This table supports the "Portal Access Management" process. It maps specific portal share instances (which define access rights or shared documents) to the individual partners (users or contacts) who have been granted access to those resources.

## Description
One row represents a single association between a portal share record and a partner record. It acts as a link table in the staging layer, representing the raw, normalized many-to-many relationship as it exists in the source database before any business logic or filtering is applied.
