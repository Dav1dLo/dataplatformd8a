# product_template_attribute_value

## Source system
This table originates from Odoo (OpenERP), as evidenced by the naming convention (`product_template_attribute_value`, `product_tmpl_id`, `create_uid`, `write_uid`) and the use of standard Odoo sequence-based primary keys.

## Functional process 
This table supports the product configuration and variant management process. It links specific attribute values (e.g., "Red", "Large") to product templates and attribute lines, allowing for the definition of product variants and associated price adjustments (`price_extra`).

## Description
One row represents a specific attribute value assigned to a product template, defining a component of a product variant. This is a raw landed staging table representing the configuration state of product attributes within the Odoo ecosystem.
