# project_task_type

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention (e.g., `create_uid`, `write_uid`, `jsonb` for translatable fields, and `_id` suffixes for relational fields) is characteristic of the Odoo ORM framework.

## Functional process 
This table supports the Project Management module, specifically defining the stages or types of tasks within a project workflow (e.g., "To Do", "In Progress", "Done"). It manages the configuration of these task types, including associated automation templates (email, SMS, rating) and UI behavior such as folding stages in a Kanban view.

## Description
One row represents a single task stage or type definition within the project management system. This is a raw landing table in the staging layer, containing the direct representation of the Odoo `project.task.type` model, including system-generated audit fields and configuration flags.
