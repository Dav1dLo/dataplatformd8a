# res_currency

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention (`res_currency`), the use of `res_` prefix common in Odoo's "Resource" module, and the presence of standard Odoo audit columns like `create_uid`, `write_uid`, `create_date`, and `write_date`.

## Functional process 
This table supports the multi-currency management process within the ERP, providing the master data for all currencies supported by the system. It is used to define currency symbols, rounding rules, and display formats for financial transactions across the platform.

## Description
One row in this table represents a single currency definition, including its display properties and rounding configuration. As a staging table, it serves as a raw, direct copy of the Odoo `res_currency` table, providing the foundational currency metadata required for financial reporting and transaction processing.

## Caveats for downstream consumers

- **Soft Deletes:** The `active` column acts as a soft-delete flag; queries should generally filter by `WHERE active = TRUE` unless historical data is required.
- **Timestamps:** Timestamps are stored in the database's local time (typically UTC in Odoo deployments), but verify against the application server configuration.
- **JSONB Fields:** `currency_unit_label` and `currency_subunit_label` contain JSONB data; use PostgreSQL `->>` operator to extract specific language values.
- **Precision:** The `rounding` column is `NUMERIC` and should be used for all financial arithmetic to avoid floating-point errors.
