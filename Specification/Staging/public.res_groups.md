## Functional process 
This table supports the Identity and Access Management (IAM) process within the ERP. It defines security groups that aggregate permissions, which are subsequently assigned to users to control access to specific modules, views, and data records.

## Description
One row in this table represents a single security or access group defined within the system. This is a raw landing table in the staging layer, containing the base configuration and audit metadata for these groups.
