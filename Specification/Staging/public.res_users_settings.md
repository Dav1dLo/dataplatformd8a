# res_users_settings

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `res_users_settings` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of the Odoo `res` (resource) module architecture.

## Functional process 
This table supports the user preference and UI configuration management process within the Odoo Discuss/Messaging module. It tracks individual user settings for communication features, such as push-to-talk configurations, notification preferences, and the state of the sidebar UI components.

## Description
One row in this table represents the specific application settings and UI state preferences for a single user. It serves as a raw landed copy of user-level configuration data, intended to be used for personalizing the user experience across the platform's communication modules.

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `user_id` → `res_users.id`: Standard Odoo pattern linking settings to the base user record.
    - `create_uid` → `res_users.id`: Audit reference to the user who performed the creation.
    - `write_uid` → `res_users.id`: Audit reference to the user who performed the last update.
- **Natural keys (inferred):** 
    - `user_id`: In Odoo, a user typically has only one settings record, making `user_id` the effective business key.

## Caveats for downstream consumers

- **Timestamps:** Odoo timestamps are typically stored in UTC; verify against the application server configuration.
- **Soft Deletes:** Odoo generally performs hard deletes on configuration tables; assume no soft-delete flag exists unless `active` column is present (not present here).
- **Audit Columns:** `create_uid` and `write_uid` refer to the internal Odoo user ID, which may not map directly to external identity provider IDs.
- **Data Types:** `VARCHAR` columns do not have defined lengths in the metadata; assume variable length based on application logic.
