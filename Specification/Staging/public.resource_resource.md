# resource_resource

## Source system
This table originates from an Odoo ERP system. The naming convention (e.g., `create_uid`, `write_uid`, `create_date`, `write_date`) and the presence of `resource_type` and `calendar_id` are characteristic of Odoo's `resource.resource` model, which manages human or material resources within the platform.

## Functional process 
This table supports the resource management and scheduling process. It defines the pool of available resources (employees, machines, or departments) that can be assigned to tasks or projects, tracking their time efficiency, timezone settings, and association with specific work calendars.

## Description
One row represents a single resource entity available for scheduling within the organization. This is a raw landing table in the staging layer, capturing the state of resource definitions as they exist in the source ERP system.

## Caveats for downstream consumers

- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` if only current resources are required.
- **Timestamps:** Timestamps are stored in the database's local time; verify if the source Odoo instance is configured for UTC.
- **Sensitivity:** The `user_id` and `company_id` columns link to internal system entities; ensure appropriate access controls are applied when joining with PII-heavy tables.
- **Precision:** `time_efficiency` is a float; use caution when performing arithmetic to avoid floating-point rounding errors.
