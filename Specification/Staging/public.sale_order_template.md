# sale_order_template

## Source system
This table originates from Odoo ERP. The naming convention (e.g., `create_uid`, `write_uid`, `write_date`, `JSONB` fields for journals) and the specific structure of the `sale_order_template` entity are characteristic of the Odoo sales module's quotation template functionality.

## Functional process 
This table supports the "Quote-to-Cash" process by managing reusable quotation templates. These templates allow sales representatives to standardize the terms, payment requirements, and automated email follow-ups for common service or product bundles, ensuring consistency across sales orders.

## Description
One row in this table represents a single quotation template configuration used to pre-populate sales orders. It acts as a raw landed copy of the Odoo configuration entity, capturing business logic such as signature requirements, payment terms, and associated email templates.

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `company_id` → `res_company.id` (Standard Odoo multi-company link)
    - `mail_template_id` → `mail_template.id` (Links to the email marketing/notification system)
    - `create_uid` / `write_uid` → `res_users.id` (Audit trail links to system users)
- **Natural keys (inferred):** None. The `name` field is descriptive but not guaranteed unique across all Odoo installations.

## Caveats for downstream consumers

- **Sensitive Data:** No direct PII, but `note` (JSONB) may contain internal business logic or customer-facing terms that should be reviewed before exposure.
- **Timestamps:** Assumed to be in UTC, consistent with standard Odoo database configurations.
- **Soft Deletes:** The `active` column is used for soft deletes; ensure queries filter by `active = TRUE` to retrieve only current templates.
- **JSONB Fields:** The `note` and `journal_id` columns contain semi-structured data; use PostgreSQL JSONB operators (e.g., `->>`) to extract specific values.
- **Precision:** `prepayment_percent` is a `DOUBLE PRECISION` float; ensure rounding is handled appropriately for financial reporting.
