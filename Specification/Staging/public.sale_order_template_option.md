# sale_order_template_option

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `sale_order_template_option`, the use of `create_uid`/`write_uid` for audit tracking, and the `JSONB` type for localized fields are characteristic of Odoo's PostgreSQL-based ORM architecture.

## Functional process 
This table supports the "Quote/Proposal Management" process. It stores optional products or services associated with a sales order template, allowing users to define "upsell" or "cross-sell" items that can be added to a quotation generated from a template.

## Description
One row represents a single optional product line item linked to a specific sales order template. It defines the quantity and unit of measure for an optional product that a customer may choose to include in their final order. This table serves as a raw landed staging entity, capturing the configuration state of template options before they are processed into downstream sales dimensions.
