# snailmail_letter

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention (e.g., `res_id`, `partner_id`, `create_uid`, `write_uid`) and the presence of `model` and `state` columns are characteristic of Odoo's ORM-based database schema.

## Functional process 
This table supports the "Snailmail" (physical mail) integration process, which allows users to send documents generated within the ERP as physical letters via third-party mailing services. It tracks the lifecycle of a letter from creation and template selection to its current delivery state, including address validation and error reporting.

## Description
One row in this table represents a single physical letter request initiated within the system. It captures the recipient's address, the associated document template, and the processing status of the mailing request. This is a raw staging table representing a direct copy of the Odoo `snailmail.letter` model.
