# stock_location

## Source system
This table originates from an Odoo ERP system, as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `parent_path`, and the specific pattern of inventory management fields like `removal_strategy_id` and `scrap_location`.

## Functional process 
This table supports the Warehouse Management System (WMS) process, specifically the definition and hierarchy of physical or logical storage locations within a warehouse. It tracks inventory positioning, replenishment rules, and accounting integration for stock valuation.

## Description
One row represents a single storage location (e.g., a shelf, bin, or loading dock) within the warehouse hierarchy. This table serves as a raw landed copy of the Odoo `stock.location` model, providing the foundational structure for inventory tracking and movement logic.

## Caveats for downstream consumers

- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing historical audits.
- **Timestamps:** `create_date` and `write_date` are assumed to be in UTC, consistent with standard Odoo deployments.
- **Hierarchy:** The `parent_path` column is a materialized path (e.g., "1/5/12"). This is highly efficient for filtering sub-locations using `LIKE '1/5/%'`.
- **Sensitivity:** No direct PII is present, but `comment` fields should be scanned for sensitive operational data.
