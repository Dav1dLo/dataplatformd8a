# stock_warehouse_orderpoint

## Source system
This table originates from an Odoo ERP system, as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `write_date`, and the specific pattern of `stock_warehouse_orderpoint` which maps to Odoo's internal inventory replenishment rules module.

## Functional process 
This table supports the inventory replenishment and supply chain planning process. It defines the minimum and maximum stock levels (reordering rules) for specific products within designated warehouse locations, triggering procurement or manufacturing orders when stock levels fall below the defined thresholds.

## Description
One row in this table represents a single reordering rule for a specific product at a specific warehouse location. It acts as a raw landing copy of the Odoo `stock.warehouse.orderpoint` model, capturing the configuration parameters that dictate when and how much inventory should be replenished.
